# ZYBlog 用户使用手册

本手册面向所有使用 ZYBlog 的用户，涵盖浏览、写作、协作和管理的完整操作流程。

---

## 用户角色

ZYBlog 有三种用户角色，权限各不相同：

| 角色 | 权限说明 |
|------|----------|
| 访客 | 浏览文章、搜索、提交评论、提交 PR |
| 账号用户 | 访客权限 + 登录后评论和 PR 自动关联账号 |
| 管理员 | 全部权限：发布文章、管理评论、审核 PR、数据备份等 |

---

## 浏览文章

### 首页

打开网站首页，可以看到已发布的文章列表，以卡片形式展示。

### 搜索文章

1. 在首页顶部找到搜索框
2. 输入关键词，搜索会自动触发（输入后约 300ms 开始搜索）
3. 搜索结果会显示匹配的文章数量
4. 点击搜索框右侧的清除按钮可以清空搜索

### 按标签筛选

1. 在搜索框下方找到标签区域
2. 点击某个标签，文章列表会只显示包含该标签的文章
3. 再次点击同一标签取消筛选，或点击"全部"恢复完整列表
4. 标签筛选和搜索可以组合使用

### 分页浏览

文章列表底部有分页控件，点击页码切换页面。每页默认显示 10 篇文章。

### 阅读文章

点击文章卡片进入文章详情页。详情页会显示：
- 发布日期
- 文章标签
- 封面图片（如果有）
- 文章正文（Markdown 渲染）
- 待办事项列表（如果有）
- Pull Requests 区域
- 评论区域

## 注册与登录

### 邮箱注册

1. 点击导航栏的"登录"按钮，进入登录页面
2. 点击底部的"去注册"切换到注册模式
3. 填写昵称、邮箱和密码
4. 点击"注册"按钮
5. 注册成功后自动跳转到首页

### 管理员首次登录

首次使用时，系统会自动创建管理员账户：

- **邮箱**：`admin@zyblog.local`
- **密码**：`dev_admin_key_change_me`（本地开发默认值）

> ⚠️ 请在首次登录后通过"个人中心"修改密码。
>
> 密码由 `.env` 文件中的 `ADMIN_KEY` 决定。生产环境请务必修改为强密码。

### 邮箱登录

1. 进入登录页面
2. 填写邮箱和密码
3. 点击"登录"按钮
4. 登录成功后自动跳转到首页

### GitHub 登录

1. 进入登录页面
2. 点击"使用 GitHub 登录"按钮
3. 跳转到 GitHub 授权页面，确认授权
4. 授权完成后自动返回博客并登录

## 文章管理（管理员）

### 创建文章

1. 点击侧边栏的"发布文章"进入编辑页面
2. 在标题区域输入文章标题
3. 在正文区域输入文章内容，支持 Markdown 语法
4. 在标签选择器中选择文章标签（可多选）
5. 点击右上角的"发布"按钮

### 使用编辑器工具栏

编辑器上方有一排工具按钮：

- **加粗按钮（B）**：选中文字后点击加粗，或使用快捷键 `Ctrl+B`
- **列表按钮**：将当前行切换为列表项
- **图片按钮**：点击后选择本地图片上传，自动插入 Markdown 图片语法
- **视频按钮**：点击后选择本地视频上传，支持 MP4、WebM、OGG 格式

### 插入图片的三种方式

1. **工具栏上传**：点击工具栏的图片按钮，选择本地文件
2. **粘贴上传**：从剪贴板粘贴图片（`Ctrl+V`）
3. **拖拽上传**：将图片文件直接拖入编辑区域

### 插入视频

1. 点击工具栏的视频按钮
2. 选择本地视频文件（最大 100MB）
3. 视频上传完成后自动插入到文章中

### 自动保存草稿

编辑新文章时，内容会自动保存到浏览器本地存储。编辑器顶部会显示保存状态（如"已保存"、"3秒前保存"）。下次进入发布页面时，之前的草稿会自动恢复。

### 快捷键

| 快捷键 | 功能 |
|--------|------|
| `Ctrl+B` | 加粗选中文字 |
| `Ctrl+S` | 手动保存草稿 |
| `Ctrl+Enter` | 发布文章 |

### 编辑已发布文章

1. 进入草稿箱或文章详情页
2. 点击"编辑"按钮
3. 修改文章内容
4. 点击"更新"按钮保存修改

### 清空编辑器

点击右上角的"清空"按钮，会清除当前编辑器中的标题和内容。已发布的文章编辑时不会触发自动保存。

## 草稿箱（管理员）

### 查看草稿

1. 点击侧边栏的"草稿箱"
2. 查看所有未发布的文章列表
3. 每篇草稿显示标题、摘要和创建时间

### 操作草稿

- **编辑**：点击"编辑"按钮，进入编辑页面修改内容
- **发布**：点击"发布"按钮，将草稿发布为正式文章
- **删除**：点击"删除"按钮，确认后删除草稿

## 导入文章（管理员）

### 从 Markdown 文件导入

1. 点击侧边栏的"导入文章"
2. 点击上传区域或拖拽 `.md` 文件到上传区域
3. 系统自动解析文件内容和 frontmatter 元数据
4. 预览解析结果，包括标题、标签、摘要、状态和内容
5. 确认无误后点击"确认导入"
6. 导入成功后自动跳转到新文章详情页

### Frontmatter 格式

导入的 Markdown 文件支持 YAML frontmatter 元数据：

```markdown
---
title: 文章标题
excerpt: 文章摘要
tags: [标签1, 标签2]
status: published
date: 2024-01-01
cover_image: https://example.com/image.jpg
---

正文内容...
```

### 注意事项

- 仅支持 `.md` 格式文件
- `status` 为 `published` 时直接发布，否则保存为草稿
- 如果 frontmatter 中没有标题，默认使用 "Untitled"

## 版本控制

每次编辑并更新文章时，系统会自动创建一个版本快照。

### 查看版本历史

1. 打开文章详情页
2. 点击文章头部右侧的"版本历史"按钮
3. 弹出版本历史面板，显示所有版本记录
4. 每个版本显示版本号、创建时间和标题

### 查看版本差异

1. 在版本历史面板中，点击某个版本的"查看 Diff"按钮
2. 弹出差异对比视图
3. 绿色行表示新增内容，红色行表示删除内容
4. 顶部显示新增和删除的行数统计

### 回滚到历史版本

1. 在版本历史面板中，点击某个版本的"回滚"按钮
2. 确认回滚操作
3. 系统将文章内容恢复到该版本的状态
4. 回滚操作本身会创建一个新版本

### 注意事项

- 回滚后当前内容会被覆盖，但可以通过再次回滚恢复
- 每次回滚都会生成新的版本号

## 评论系统

### 提交评论（所有用户）

1. 打开文章详情页
2. 滚动到评论区域
3. 填写称呼（必填）和邮箱（可选）
4. 输入评论内容
5. 点击"提交评论"按钮
6. 提交后显示"评论已提交，等待审核"的提示

### 查看评论

文章详情页的评论区域会显示所有已审核通过的评论，包括作者名称、时间和评论内容。

### 审核评论（管理员）

1. 点击侧边栏的"评论管理"
2. 查看待审核评论列表，包括作者、邮箱、关联文章和评论内容
3. 点击"通过"按钮审核通过评论
4. 点击"删除"按钮删除评论，需确认操作

## PR 协作

PR（Pull Request）功能允许读者对文章提出修改建议，类似于代码协作中的 Pull Request。

### 提交 PR

1. 打开文章详情页
2. 在文章正文中用鼠标选中一段文字
3. 页面顶部会出现选择操作栏，显示已选中的文本
4. 点击"创建 PR"按钮
5. 在弹出的表单中：
   - "替换为"：修改建议的替换内容（默认为选中的原文）
   - "说明"：解释为什么需要这个修改（可选）
   - "PR 描述"：总体描述（可选）
   - "邮箱"：你的联系邮箱（必填）
6. 点击"提交 PR"

### 查看 PR 列表

文章详情页的 PR 区域会显示所有 PR，包括：
- 提交者邮箱
- 修改数量
- PR 状态（开放/已关闭/已合并）
- 提交时间

支持按状态筛选：全部、开放、已关闭、已合并。

### 查看 PR 详情

点击某个 PR 卡片进入详情视图，可以看到：
- PR 描述信息
- 所有修改片段，每个片段显示原文和替换内容的对比
- 片段上的评论

修改片段会在文章正文中高亮显示。

### 内联评论

在 PR 详情中，可以对每个修改片段发表评论：
1. 在片段下方的评论区域输入邮箱和评论内容
2. 点击"发送评论"

### 审核 PR（管理员）

1. 打开 PR 详情
2. 查看修改内容和评论讨论
3. 如果同意修改，点击"合并 PR"按钮
4. PR 状态会变为"已合并"，文章内容自动更新

## TODO 管理

### 什么是 TODO？

TODO 是文章中的待办事项标记。博主在写文章时可以使用 `#todo` 标记来记录需要完成的任务，读者可以订阅感兴趣的 TODO，在任务完成时收到邮件通知。

### 如何创建 TODO？

在文章编辑器中，直接输入 `#todo` 后跟待办事项的描述即可。每行一个 TODO：

```
#todo 完成用户认证功能
#todo 添加搜索功能
#todo 优化数据库查询
```

系统会自动从文章内容中提取所有 `#todo` 标记，在文章详情页以待办事项列表的形式展示。

### 在文章中查看 TODO

1. 打开包含待办事项的文章
2. 文章正文下方会显示"待办事项"区域
3. 每个待办项显示完成状态（○ 未完成 / ✓ 已完成）和标题
4. 已完成的事项会显示删除线样式

### 管理 TODO（管理员）

博主可以在专门的管理页面统一查看和处理所有 TODO：

1. 点击侧边栏的"TODO 管理"
2. 查看所有文章中的待办事项，按文章分组显示
3. 使用顶部筛选标签切换查看范围：
   - **全部**：显示所有 TODO
   - **未完成**：只显示尚未完成的 TODO
   - **已完成**：只显示已标记完成的 TODO
4. 每个待办项旁边显示当前订阅人数
5. 点击"完成"按钮，将待办事项标记为已完成

### 订阅 TODO（读者）

读者可以订阅感兴趣的待办事项，在任务完成时收到邮件提醒。

**已登录用户：**
1. 在文章详情页的待办事项区域找到感兴趣的 TODO
2. 点击右侧的"订阅"按钮
3. 订阅成功，当 TODO 被标记为完成时会收到邮件通知

**未登录用户：**
1. 在待办项右侧的输入框中填写邮箱地址
2. 点击"订阅"按钮（也可以直接按回车键）
3. 订阅成功

### 取消订阅

已订阅的待办项右侧会显示"取消订阅"按钮，点击即可取消，后续不再收到该 TODO 的通知。

### 邮件通知

当博主在 TODO 管理页面将某个待办事项标记为完成时，系统会自动向所有订阅了该 TODO 的用户发送邮件通知。

邮件内容包含：
- TODO 标题
- 所属文章标题
- 完成时间

收到邮件后，你可以点击链接直接跳转到对应文章查看详情。

## 媒体管理（管理员）

### 上传文件

1. 点击侧边栏的"媒体管理"
2. 有三种上传方式：
   - 点击"上传文件"按钮选择文件
   - 点击上传区域选择文件
   - 将文件直接拖拽到上传区域
3. 支持批量上传多个文件

### 支持的格式

- 图片：JPEG、PNG、GIF、WebP
- 视频：MP4、WebM
- 单个文件最大 100MB

### 查看文件列表

媒体管理页面以网格形式展示所有上传的文件，每个文件卡片显示：
- 缩略图（图片）或视频图标
- 文件名
- 文件类型和大小
- 上传时间

### 预览文件

点击文件卡片的缩略图区域，弹出预览窗口：
- 图片：全尺寸显示
- 视频：带播放控件的视频播放器

### 删除文件

点击文件卡片上的"删除"按钮，确认后删除文件。删除操作不可撤销。

### 分页

文件列表底部有分页控件，支持浏览大量文件。

## 数据备份（管理员）

### 创建备份

1. 点击侧边栏的"数据备份"
2. 点击"创建备份"按钮
3. 等待备份完成
4. 备份文件会出现在备份列表中

### 查看备份列表

备份列表显示所有备份文件，包括：
- 文件名
- 文件大小
- 创建时间

### 恢复备份

1. 在备份列表中找到要恢复的备份
2. 点击"恢复"按钮
3. 确认恢复操作（注意：此操作会覆盖当前数据库数据，不可撤销）
4. 等待恢复完成

### 注意事项

- 恢复操作会覆盖当前所有数据
- 建议在恢复前先创建一个新备份
- 备份文件不会自动清理，请定期手动管理

## 主题切换

1. 点击页面顶部的主题切换按钮（太阳/月亮图标）
2. 在深色模式和浅色模式之间切换
3. 主题偏好会自动保存，下次访问时保持上次选择

## 导出文章（管理员）

管理员可以通过 API 导出所有文章数据：

### JSON 导出

访问 `/api/v1/export/posts` 并携带管理密钥，可导出 JSON 格式的全部文章。

### CSV 导出

访问 `/api/v1/export/posts?format=csv` 并携带管理密钥，可导出 CSV 格式。

### 按状态筛选

添加 `status=published` 或 `status=draft` 参数可以只导出特定状态的文章。

## 常见问题

### 忘记管理密钥怎么办？

管理密钥在后端环境变量 `ADMIN_KEY` 中配置。请联系服务器管理员重置。

### 评论提交后为什么不显示？

所有评论需要管理员审核后才会公开显示。请耐心等待。

### 上传的文件存储在哪里？

上传的图片和视频存储在后端服务器的 `backend/static/` 目录中，通过 URL 直接访问。

### PR 合并后文章内容没有更新？

合并 PR 后需要刷新页面查看最新内容。如果仍有问题，请检查 PR 状态是否为"已合并"。

### 导入文章时提示格式不支持？

导入功能仅支持 `.md`（Markdown）格式文件。请确保文件扩展名为 `.md`。
